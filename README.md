# Guilherme Moura — Portfólio

Portfólio estático com três projetos demonstrativos e um briefing de clientes.

## Páginas
- `index.html`: portfólio e contato.
- `barbearia.html`: Moura Studio.
- `concessionaria.html`: Só Veículos — conceito independente.
- `clinica.html`: Clínica Viotto — conceito independente.
- `briefing.html`: preferências visuais, resumo e envio pelo WhatsApp.

## Uso
Abra `index.html` no navegador. Não exige instalação nem compilação.
Todas as páginas usam links relativos e podem ser publicadas juntas em um serviço de hospedagem estática. Para GitHub Pages, configure a publicação pela branch `main`, pasta raiz.

## Conteúdo
Há marcas fictícias e um conceito independente inspirado na Só Veículos, identificado na página. Catálogo, preços e agendamentos são demonstrativos. As imagens são referências de bancos de imagens, com créditos nas páginas. Fotografias e fontes são carregadas de serviços externos e precisam de internet.
